🧬 논문 피규어용 유전자 맵 스튜디오 사용 가이드
논문 피규어용 유전자 맵 스튜디오는 복잡한 일러스트레이터 작업 없이, GenBank(.gb) 파일만으로 출판 품질(Publication-quality)의 WT(Wild Type) 및 Mutant 유전자 모식도를 그려주는 도구입니다.
이 가이드를 따라 클릭 몇 번만으로 깔끔한 피규어를 완성해 보세요!
🚀 빠른 시작 (Quick Start)
1.	[📂 파일 업로드] 탭에서 WT와 Mutant의 GenBank(.gb 또는 .gbk) 파일을 각각 업로드합니다.
2.	[🛠️ 요소 편집] 탭에서 피규어에 표시할 유전자, 제한효소(Enzyme), 프라이머 등의 위치와 이름을 입맛에 맞게 켭니다/끕니다.
3.	[⚙️ 컨트롤 패널] (왼쪽 사이드바)에서 색상, 텍스트 서식, 글씨 크기를 조절합니다.
4.	[🖼️ 미리보기 & 다운로드] 탭에서 완성된 피규어를 확인하고 고해상도(PDF, SVG, PNG)로 다운로드합니다.

📖 상세 기능 설명
1. 📂 파일 업로드
분석하고자 하는 서열의 GenBank 파일을 업로드하는 공간입니다.
•	WT GenBank: 야생형(기준) 서열 파일을 업로드합니다.
•	Mutant GenBank: 변이가 일어난(Knock-out, Knock-in 등) 서열 파일을 업로드합니다.
💡 Tip: 파일을 업로드하면 프로그램이 자동으로 서열 내의 Feature(CDS, Primer, Promoter, Enzyme 등)를 인식하여 분류합니다.
단, Primer, restriction enzyme site 등을 Add feature로 저장해야 합니다. 기본적으로 설정된 restriction enzyme site와, Add primer 기능으로 저장된 primer 특성은 GenBank file에 출력이 되지 않습니다. 각 요소 별로 자주 사용되는 이름은 설정되어 있으므로, feature의 종류는 크게 중요하지 않으나, exon은 exon 카테고리로 저장해주세요.

2. 🛠️ 요소 편집 (핵심 기능)
자동으로 인식된 유전자 요소들을 도식화하기 위해 디테일하게 설정하는 엑셀 형태의 에디터입니다. WT와 Mutant 각각 설정이 가능합니다.
•	표시 (체크박스): 피규어에 해당 요소를 띄울지 말지 결정합니다. 화면이 너무 복잡하다면 불필요한 요소는 체크 해제하세요.
•	📝 이름: 피규어에 표시될 라벨 이름을 수정할 수 있습니다. (서식 적용 가능! 아래 '텍스트 서식 꿀팁' 참고)
•	📏 선 길이 (Enzyme/Primer): 제한효소나 프라이머의 지시선 길이를 배수로 조절합니다. 요소들이 겹칠 때 길이를 조절해 가독성을 높일 수 있습니다.
•	↕️ Y 띄우기: 요소의 상하 위치를 미세 조정합니다. (예: 겹쳐있는 두 프라이머 중 하나를 약간 위로 올릴 때 사용)
•	⬆️ 위로 (체크박스): 제한효소 선이나 프라이머 방향을 기본 방향의 반대(위/아래)로 뒤집습니다.
3. 🔗 HR 연결 (Homologous Recombination)
WT와 Mutant 사이의 상동재조합(HR) 일치 구간을 X자 형태의 점선으로 이어주는 기능입니다.
•	켜져있는 요소 중 서로 연결할 WT 이름과 Mutant 이름을 쌍으로 입력하면, 두 구간이 자동으로 연결됩니다.
•	왼쪽 패널의 **[🔧 기타] -> 'HR 점선 표시'**가 체크되어 있어야 화면에 나타납니다.
4. ⚙️ 사이드바 컨트롤 패널 (디자인 & 스타일링)
논문 저널의 규정에 맞게 피규어의 디자인을 완벽하게 통제할 수 있습니다.
•	💾 프리셋 (내 기본값): 공들여 맞춘 글꼴 크기와 색상 설정을 JSON 파일로 저장해두고, 다음 작업 때 한 번에 불러올 수 있습니다.
•	📝 라벨 & 텍스트: WT/Mutant의 대표 이름과 위치를 지정합니다.
•	🔠 글씨 크기 & 🎨 색상: Exon, Marker, Enzyme, Promoter, Probe 등 각 요소별 색상과 텍스트 크기를 개별적으로 지정합니다.
•	📏 크기 & 두께: 유전자 박스의 뚱뚱한 정도, 지시선의 두께 등을 조절합니다.
•	🖼️ 캔버스 & 크롭: * 크롭 (시작/끝 bp): 10,000bp 서열 중 특정 2,000bp 구간만 확대해서 보고 싶을 때 사용합니다.
o	DPI: 해상도를 결정합니다. 논문 제출용이라면 300 또는 600을 권장합니다.

💡 텍스트 서식 꿀팁 (논문용 이탤릭/첨자 넣기)
논문 피규어의 핵심은 정확한 유전자 표기법입니다. [📝 이름] 칸이나 라벨 입력 칸에 아래의 기호를 사용하면 자동으로 예쁘게 변환됩니다.
원하는 결과	입력 방법 (코드)	예시
이탤릭체 (유전자명)	앞뒤로 별표 1개 *	*car1*
굵게 (강조)	앞뒤로 별표 2개 **	**WT**
굵은 이탤릭체	앞뒤로 별표 3개 ***	***car1***
위첨자 (Superscript)	앞뒤로 꺾쇠 ^	car1^Δ^ (car1<sup>Δ</sup>로 표시)
아래첨자 (Subscript)	앞뒤로 물결 ~	p~TEF1~ (p<sub>TEF1</sub>로 표시)
응용 예시: **car1^Δ^** 라고 입력하면 car1<sup>Δ</sup> 처럼 굵고 위첨자가 적용된 텍스트로 렌더링됩니다!

📥 다운로드 포맷 추천
완성된 피규어는 세 가지 포맷으로 다운로드할 수 있습니다.
•	📸 PNG (이미지): 프레젠테이션(PPT)이나 웹 게시용으로 적합합니다. (DPI 설정 적용됨)
•	🎨 SVG (벡터 이미지): 화질 깨짐이 없으며, 다운로드 후 Adobe Illustrator 등에서 추가로 세밀한 수정(글씨 위치 조정 등)을 할 때 가장 추천하는 포맷입니다.
•	📄 PDF (문서): 논문 원고에 바로 첨부하거나 고해상도 인쇄용으로 적합합니다.
